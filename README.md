# Simplified Player Corpse Mod For Vintage Story

Heavily based on/copied from the [Player Corpse Mod](https://github.com/DArkHekRoMaNT/PlayerCorpse) for Vintage Story but with a copy key differences.
This remake does not depend on the Common Library, and picking up the items from the corpse is just a collect action. Additionally, the corpse compass has been removed as well as the ability to make the corpses destroyable.
